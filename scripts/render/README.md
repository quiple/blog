# 가사 영상 렌더링

```sh
nub exec playwright install chromium --only-shell
nub run render anger-management
```

`ffmpeg`, `ffprobe`, `yt-dlp`가 PATH에 있어야 합니다. 결과는
`renders/anger-management.mp4`에 저장됩니다. 생성 파일은 Git에서 제외됩니다.
기존 출력이 있으면 중단하며 `--force`로 덮어쓸 수 있습니다.

```sh
# 짧은 미리보기
nub run render anger-management --seconds 20 --output renders/preview.mp4
# 이미 받은 동일한 MV 사용
nub run render anger-management --file ./mv.mp4
# 화면과 구간 설정 (시간은 MV 기준 초)
nub run render anger-management --font theme --width 1920 --height 1080 --fps 60 --start 30 --seconds 15
```

모든 출력은 **다크 모드·16:9 영역 캡처**입니다. 별도의 `--theme`, `--crop`
옵션은 없습니다. 기본값은 1920×1080, 60fps, 테마 폰트, MV 전체 길이입니다.
`--font system`은 실행 컴퓨터의 시스템 폰트를 사용합니다.

영상 전용 배치에서는 임베드·제목·연도·아티스트명 전체 묶음을 프레임 세로 중앙에
맞춥니다. 활성 가사는 일반 페이지의 자동 스크롤 기준(뷰포트 높이의 18%, 최소 96px)과
임베드 상단의 차이를 유지합니다. 처음 로드된 첫 행의 위치를 기준으로 삼지 않습니다.
1920×1080 기준 임베드 왼쪽 여백과 임베드·가사 사이의 시각적
간격은 64px입니다. 제목과 아티스트 표시는 임베드 아래에 유지하며, 이동으로
프레임 안에 들어온 제공자 버튼은 숨깁니다. MV 선택 상태 자체는 유지됩니다.

영상에서는 가사·발음·번역·곡 정보의 글자 크기를 75% 키웁니다.
기존 페이지의 폰트와 색상, AMLL을 재사용하며 일반 페이지의 배치는 변경하지
않습니다. 1920px 기준 CSS 배치를 유지한 채 브라우저의 렌더링 배율로 처음부터
출력 해상도(기본 1920×1080) 그대로 프레임당 한 번 캡처합니다. 해상도 확대·축소와
시간 샘플 합성은 하지 않습니다.

YAML의 `yt.mv` 영상을 다운로드해 **MV가 선택된 상태**의 원래 임베드
위치에 표시합니다. 영상 크기, 레터박스, 모서리는 원래 배치를 따릅니다.
YouTube 컨트롤 UI 대신 MV 자체가 표시됩니다. 최종 오디오는 동일한 MV에서
가져오며, 가사에는 기존 `offsets.ytMV`와 200ms 강조 전환 보정을 적용합니다.
`--file`은 이 MV와 타이밍이 같은 영상이어야 합니다.

렌더링 모드는 로컬 개발 서버에 CLI가 주입한 설정으로만 활성화됩니다.
공개 사이트의 쿼리나 사용자 설정을 변경하지 않으며, **영상에서만 AMLL의 비활성 행 블러를
해제**합니다. 일반 페이지의 블러는 그대로 유지합니다.

JavaScript 타이머/rAF는 Playwright Clock으로, CSS/WAAPI 애니메이션은 별도
프레임 시계로 진행합니다. 문서 스크롤 목적지는 기존 코드를 따르되, 브라우저마다
다르고 실제 시간에 의존하는 네이티브 smooth scroll은 출력 시에만 400ms ease로
바꿉니다. 따라서 네이티브 스크롤의 가속 곡선까지 동일하지는
않습니다. `--start`도 앞 프레임의 상태를 순서대로 진행한 후 해당 구간을 저장합니다.

움직이는 음절만 합성 레이어에 올려 소수 픽셀 이동을 유지하고, 움직임이 끝나면
레이어 힌트를 해제합니다. 확대·발광하는 강조 글자는 현재 폰트로 한 번 그린
작은 Canvas 텍스처를 이동·확대하여, 매 프레임 글자 윤곽을 다시 맞추지 않습니다.
레이아웃용 원문은 보존하고, 발광은 그림자 필터로 옮깁니다. 강조 글자는 효과가 끝난 뒤에도
같은 텍스처와 합성 레이어를 유지하여 텍스트 복원 시의 위치 튐을 막고, 해당 DOM이 제거되거나
렌더 브라우저가 닫힐 때 해제합니다. 일반 웹페이지와 전체 프레임 해상도는 변경하지 않습니다. 프레임 시계·MV 탐색·캡처 영역 계산은 한 번의 브라우저
호출로 처리합니다. 출력 해상도와 PNG 캡처 품질은 낮추지 않습니다.

MV를 프레임별로 탐색해 페이지에 합성하고 PNG를 FFmpeg에 바로 전달하므로
전체 프레임을 메모리나 디스크에 쌓지 않습니다. H.264 영상은 재압축하지 않고
재사용하며, 호환되지 않는 형식만 브라우저용으로 변환합니다. 임시 파일은 완료/오류
시 정리됩니다. 렌더링 속도는 영상 길이, 해상도, 컴퓨터 성능에 따라 달라집니다.

```sh
nub exec tsc -p scripts/render/tsconfig.json
node --test scripts/render/clock.test.ts
```
